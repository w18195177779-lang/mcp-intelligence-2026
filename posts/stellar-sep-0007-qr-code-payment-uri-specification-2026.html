Stellar SEP-0007 QR Payment URIs: Seamless Web3 Point-of-Sale

Standardizing mobile wallet payment requests with URI schemes, asset contracts, and cryptographic memo bindings.

Ecosystem Standard: SEP-0007 defines standard URI handlers (web+stellar:pay?destination=...) allowing mobile wallets (Lobstr, Freighter, xBull) to parse recipient addresses, exact token amounts, asset issuer signatures, and transaction memos from a single QR scan without error-prone manual input.

SEP-0007 URI Query Parameter Specification

ParameterRequiredFormat & ValidationDescription
destinationYes56-character Stellar public key (G...)Recipient account address
amountNoDecimal string (e.g. "12.50")Exact payment amount in token units
asset_codeNo1-12 alphanumeric charactersAsset code (e.g. "USDC" or "XLM")
asset_issuerConditional56-character account addressRequired if asset_code is non-native
memoNoUTF-8 string (<= 28 bytes)Reference identifier or invoice ID

Security Architecture

To prevent man-in-the-middle URI parameter tampering in web applications, point-of-sale displays should sign payment parameters using an authenticated merchant keypair, embedding the cryptographic signature directly into the SEP-0007 payload.
