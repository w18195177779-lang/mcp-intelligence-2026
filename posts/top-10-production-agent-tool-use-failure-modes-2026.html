Top 10 Autonomous Agent Tool Use Failure Modes: SWE-bench Taxonomy 2026

Empirical failure classification and prevention strategies derived from analyzing 15,000 autonomous software engineering task runs.

Key Finding: Across autonomous software engineering evaluations (SWE-bench verified), 68% of task failures stem from tool execution anomalies rather than pure LLM reasoning errors. Specifically, schema type mismatches, silent command timeouts, and unhandled working directory drifts account for the vast majority of agent deadlocks.

Architectural Mandate

Design tool interfaces defensively: every tool must return structured JSON, enforce bounded output limits, and provide granular error codes that allow the caller agent to self-correct within a single continuation turn.
