Agent Prompt Ordering Architecture

To maximize cache hit ratios, agents must arrange context monotonically: [Static System Instructions] -> [Tool Definitions] -> [Repository Schema] -> [Dynamic History]. Placing dynamic timestamps at the prompt head invalidates the entire cache tree.
